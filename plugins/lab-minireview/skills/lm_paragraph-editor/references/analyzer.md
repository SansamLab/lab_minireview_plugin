# Pass 1 — Structural Analysis Reference

This document defines the structural analysis pass. Pass 1 diagnoses a paragraph's controlling idea, topic sentence, sentence hierarchy, unity, coherence, and clause organization, then produces a structurally-revised paragraph. The styling pass (Pass 2) runs separately on Pass 1's revised paragraph.

Analyze first. Revise only after the hierarchy is clear.

---

## Foundational principle

Every sentence in a paragraph should have a hierarchical job. A paragraph is coherent when every sentence can be placed in a clear hierarchy:

```
controlling idea → major (primary) support → minor (secondary) support
```

Each link in that hierarchy must pass a connector test.

The writer's process is:

1. Develop a controlling idea.
2. Develop a topic sentence.
3. Make a list of major and minor supporting statements.
4. Test each supporting statement to ensure unity with the controlling idea.
5. Organize all supporting statements into a coherent order.

Pass 1 follows this process in reverse when diagnosing an existing paragraph.

---

## The 11-step workflow

Unless the user asks for a quick rewrite, proceed in this order:

1. Identify the controlling idea.
2. Evaluate where and how it appears.
3. Identify and evaluate the topic sentence.
4. Classify each sentence by role and evidence type.
5. Test every support for unity.
6. Identify extraneous, misplaced, redundant, or unsupported material.
7. Identify the development method and check pitfalls.
8. Assess sentence order and coherence.
9. Test compound and complex sentences for coordination, subordination, connectives, and clause emphasis.
10. Produce a revision plan.
11. Produce a structurally-revised paragraph.

Each step is detailed below.

---

## 1. Controlling idea

The controlling idea is the central thought that governs the paragraph. It is the central claim, not the topic.

A topic sentence should contain both:
- the topic,
- the controlling idea.

A topic without a controlling idea is too broad.

State the controlling idea in one sentence.

Output:
- Controlling idea:
- Simple or compound?
- If compound: component A, component B, relationship between them.

### Compound controlling idea

A central thought may have multiple controlling ideas. A compound controlling idea is acceptable only when:
- its parts are related,
- together they perform one paragraph-level job,
- each component has its own support.

A compound controlling idea can be developed by comparison or contrast. Each part is tested with the same principles used for a single controlling idea.

## 2. Placement and phrasing

Tell where the controlling idea appears: first sentence, middle, final sentence, implied, absent, or split.

Judge whether placement and phrasing work:
- Does it orient the reader early?
- Is it a definite claim, not just a topic?
- Does it predict the paragraph?
- Is it too broad, too narrow, vague, or different from what the paragraph proves?

If needed, propose a sharper version before revising.

## 3. Topic sentence

Identify the topic sentence if present.

Output:
- Topic sentence:
- Contains the controlling idea?
- Works where located?
- Forecasts the support structure?
- Revise, move, split, or replace?

## 4. Sentence hierarchy map

Number every sentence. Classify each by role and evidence type.

**Roles:**
- `TS` — topic sentence
- `P` — primary (major) support: directly supports the controlling idea
- `S` — secondary (minor) support: supports a primary support, word, phrase, or clause
- `X` — extraneous
- `M` — misplaced
- `U` — unclear role

**Evidence types:**
- `D` — detail (makes an idea more precise)
- `I` — illustration, example, fact, observation, case, or data point
- `R` — reason (explains why a claim is true, or what follows from it)

Use this table:

| # | Sentence idea | Role | Type | Supports | Diagnosis |
|---|---|---|---|---|---|

## 5. Unity tests

Primary supports are tested against the controlling idea. Secondary supports are tested against the primary support (or word, phrase, or clause) they support.

**Connectors:**
- *because* = reason
- *therefore* = consequence or implication
- *specifically* = detail
- *for instance* = illustration, example, observation, fact, or data

**Test forms:**
- [Controlling idea] because/therefore/specifically/for instance [primary support].
- [Primary support] because/therefore/specifically/for instance [secondary support].

Use the same connector within a tested group unless deliberately diagnosing mixed support types.

When working with data, facts, observations, cases, events, or examples, prefer *for instance* rather than *because*, unless the sentence is genuinely causal or explanatory.

| # | Test sentence | Pass/fail | Diagnosis |
|---|---|---|---|

If a sentence fails the test, specify whether to cut, move, promote, subordinate, or rewrite it.

## 6. Extraneous or misplaced material

Unity is achieved by elimination. Coherence is achieved by organization. Do not optimize coherence until extraneous material has been identified.

List sentences that:
- belong,
- are extraneous,
- are misplaced,
- need a clearer link to the controlling idea,
- introduce a second controlling idea.

## 7. Development method check

Identify the paragraph's development method.

- **Simple methods:** detail, reason, illustration/example.
- **Complex methods:** definition, comparison, contrast, analogy.

Mixed methods are allowed if the hierarchy is clear.

**Pitfalls to check:**
- *Definition*: circular, too broad, too narrow, inconsistent, replaced by examples, purposeless.
- *Comparison*: unclear basis, shifting criteria, unequal treatment, weak parallelism, unsupported similarity.
- *Contrast*: not sustained, one side underdeveloped, mere description, shifting basis, misused contrast transitions.
- *Analogy*: false, decorative, overextended, unclear mapping, used as proof, misleading tone or domain.
- *Mixed*: support types lack hierarchy; examples replace interpretation; details interrupt reasoning.

Output:
- Development method:
- Fits controlling idea?
- Maintained throughout?
- Pitfalls present:
- Fix:

## 8. Sentence order and coherence

After deciding what belongs, assess sentence order. Identify the organizing principle and test whether it is maintained.

**Ordering principles:**
- time
- space
- specificity (general to specific or specific to general)
- importance
- cause-to-consequence
- reason-to-conclusion
- problem-to-solution
- comparison/contrast
- examples
- major-support clusters

Maintain the chosen principle. Flag unsignaled shifts.

Also check:
- **Point of view** — no unexplained shifts in subject, tense, person, narrator, or vantage point.
- **Pronouns** — every pronoun clearly refers to one antecedent.
- **Transitions** — accurately show addition, contrast, cause, consequence, time, condition, example, or specification.

Output:
- Current ordering principle:
- Best ordering principle:
- Maintained?
- POV shifts:
- Pronoun problems:
- Transition problems:
- Sentences out of order:
- Recommended order:

**Diagram form:**
```
(TS) Topic sentence.
(I-R/D/I) Primary support.
    (A-R/D/I) Secondary support.
    (B-R/D/I) Secondary support.
(II-R/D/I) Primary support.
    (A-R/D/I) Secondary support.
```

Use `(TS)` before the topic sentence, Roman numerals before each major statement, capital letters before each minor statement, and a `-R`, `-D`, or `-I` suffix for evidence type.

## 9. Clause organization and connectives

Analyze compound and complex sentences after hierarchy is clear.

### Coordination and subordination

- Coordination shows equality of value between ideas.
- Subordination shows difference in value.
- A sentence is unified when its grammar gives each idea the weight it deserves.

**Compound sentences:** Each independent clause receives emphasis and should directly support the controlling idea. If one clause is secondary, subordinate it.

Check:
- Are clauses equal in value?
- Do both support the controlling idea?
- Is the connective accurate?

If one clause is method, background, timing, qualification, or detail, subordinate it.

**Complex sentences:** The independent clause should contain the main idea. Dependent clauses provide secondary information. Flag sentences that bury the main claim in a dependent clause.

### Coordinating conjunctions

- *and* — addition or continuation
- *or* — alternative
- *but* — contrast or exception
- *therefore, consequently* — consequence
- *for* — reason
- *nor* — continues a negative thought
- *yet* — contrast despite obstacle
- *so* — consequence or result

### Subordinating conjunctions (adverbial clauses)

Turn the clauses they introduce into dependent adverbial clauses expressing time, cause, condition, concession, contrast, or limitation.

- *time*: after, before, when, while, since, until
- *cause*: because, since, as
- *condition*: if, unless
- *concession*: although, even though, though

### Relative pronouns (adjectival clauses)

Introduce dependent clauses functioning as adjectives, identifying or describing a noun.

- who, whose, whom, which, what, that

### Output table

| Sentence # | Clause/connective issue | Diagnosis | Suggested fix |
|---|---|---|---|

### Coordination/subordination correction method

When several sentences have miscoordinated or missubordinated ideas:

1. List each idea separately and number it.
2. Identify the controlling idea.
3. Classify each idea as main or subordinate (use the *because* test).
4. Main ideas directly support the controlling idea.
5. Subordinate ideas support a word, phrase, or clause and indirectly support the controlling idea.
6. Group related main and subordinate ideas.
7. Combine the ideas with the correct grammatical hierarchy.

## 11. Structurally-revised paragraph

Produce a revised paragraph that:

- preserves meaning,
- states the controlling idea clearly,
- keeps only unified material,
- uses an appropriate development method,
- maintains coherent order and consistent POV,
- uses clear pronouns and accurate transitions,
- coordinates equal ideas and subordinates secondary ideas,
- places main ideas in independent clauses,
- avoids unsupported new claims.

This revised paragraph becomes the input for Pass 2 (sentence styling).

---

## Behavior rules

- Do not revise before testing sentences.
- A sentence is not unified merely because it is on the same topic; it must support the controlling idea directly or indirectly.
- Do not treat a paragraph as coherent until extraneous material has been identified.
- When uncertain about a sentence's role, mark it as `U` and explain why.
- In scientific writing (when scientific mode is active), preserve precision. Flag causal language when support only shows association or illustration. Do not let a revision overclaim.
- Prefer diagnostic feedback over praise.

## Interactive prompts during Pass 1

Pass 1 includes two user-facing prompts at specific decision points. The prompts use `ask_user_input_v0`. After each prompt, Pass 1 resumes where it left off.

### Prompt 2 — Controlling-idea disambiguation

**Fires after step 1 (Identify the controlling idea), before step 2.**

Fire this prompt when there are two or more plausible readings of the central claim. Specifically:

- The paragraph could be read as either single or compound controlling idea (e.g., "X requires Y" versus "X requires Y, and we lack a framework for understanding Y").
- The main claim could plausibly be in different sentences (e.g., the first sentence and the last sentence each work as topic sentences).
- The topic sentence is implied or split, making the central claim recoverable in more than one way.
- The paragraph has a strong first sentence and a strong final sentence, and they make different claims.

Do NOT fire this prompt when:

- The controlling idea is clear (only one defensible reading).
- The paragraph is very short (1–2 sentences).
- The user has already specified the controlling idea in their request (e.g., "the main point I'm trying to make is...").

When firing, generate 2–3 candidate phrasings of the controlling idea in plain language. State each candidate as the user would think of it, not in technical analyzer language. Add a fourth option: "Something else — let me state it."

Phrasing template for the question:

> "This paragraph has more than one plausible reading. Which is the central claim the rest of the analysis should build on?"

After the user answers, document the selection in the analysis file and proceed with that controlling idea as fixed.

### Prompt 3 — Subordination disambiguation (selective)

**Fires during step 9 (Clause organization and connectives).**

Fire this prompt when Pass 1 would normally demote a clause to subordinate position, but the relative weight of the two clauses is genuinely debatable. Specifically:

- Both clauses make claims that could plausibly support the controlling idea directly.
- The original sentence treats the clauses as equal (coordination), and demoting one would change which idea gets grammatical emphasis.
- A reasonable editor could argue either way about which clause is the main idea.

Do NOT fire this prompt when:

- Subordination is obvious (one clause is plainly background, condition, qualification, or detail).
- The sentence is fine as written and no subordination change is needed.
- The user has asked for "minimal changes" or similar restraint.
- The subordination decision affects fewer than two clauses.

If multiple debatable subordinations exist in the paragraph, batch them into a single `ask_user_input_v0` call with up to three questions. If subordination decisions are all clear-cut, no prompt fires.

For each question, generate:

- The original sentence verbatim, labeled "Keep as is — both clauses equal."
- One option demoting clause A.
- One option demoting clause B (optional, if it produces a meaningfully different result).

Phrasing template for the question:

> "I'm not sure which idea should be the main clause in sentence [N]. Which way reads right?"

After the user answers, document the selection in the analysis file and apply the chosen revision.
