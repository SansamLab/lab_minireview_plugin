# lab-minireview marketplace

A Claude plugin marketplace containing one plugin, lab-minireview. It turns a research topic into a verified minireview (.docx) with an annotated bibliography.

## Install

In Claude Code, add the marketplace:

`/plugin marketplace add SansamLab/lab_minireview_plugin`

Then install the plugin:

`/plugin install lab-minireview@lab-minireview-marketplace`

## What is inside

The plugin lives in [plugins/lab-minireview](plugins/lab-minireview). See its [README](plugins/lab-minireview/README.md) for the skills and pipeline stages, and [CONNECTORS.md](plugins/lab-minireview/CONNECTORS.md) for the required connectors (PubMed) and tools.
